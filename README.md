# Cyber Security Lab Setup
Cybersecurity Internship | Week 1 | Cyber Security Lab Setup
Lab Setup: VirtualBox & Kali Linux

During the first week of my cybersecurity internship, I worked on setting up a virtual lab environment for cybersecurity and ethical hacking practice.

Tasks Covered:

• Installed and configured Oracle VirtualBox.
• Imported and configured Kali Linux as a virtual machine.
• Created a NAT Network using the "10.0.0.0/24" subnet.
• Configured Kali Linux with the static IP address "10.0.0.2/24".
• Worked on configuring internet connectivity for Kali Linux.
• Reviewed virtual machine settings, including clipboard sharing and drag-and-drop.
• Configured shared folders to exchange files between the host system and the virtual machine.
• Learned about taking virtual machine snapshots to save the lab state and support recovery.

Learning Outcomes:

This lab helped me understand virtualized lab environments, basic network configuration, IP addressing, and the importance of preparing a controlled environment for cybersecurity and ethical hacking exercises.

Looking forward to building my practical cybersecurity skills and learning more about network security and penetration testing.
